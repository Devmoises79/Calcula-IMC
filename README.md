# 🧮 Calcula IMC - C# Console

Projeto simples em C# que calcula o IMC (Índice de Massa Corporal) a partir de dados inseridos pelo usuário via terminal.

## 🎯 Objetivo
Este projeto tem foco educacional, com ênfase no domínio de fundamentos da linguagem C#, especialmente manipulação de variáveis, entrada de dados e operações matemáticas.

## ⚙️ Funcionalidades
- Entrada de dados do usuário (nome, idade, altura e peso)
- Conversão de tipos com `int.Parse` e `double.Parse`
- Cálculo do IMC com fórmula padrão
- Exibição formatada do resultado

## 🧠 Fórmula utilizada
IMC = peso / (altura × altura)

## 🛠️ Tecnologias
- C#
- .NET Console Application

## 📌 Conceitos aplicados
- Variáveis e tipos de dados
- Entrada e saída via console
- Conversão de dados (Parse)
- Operações matemáticas básicas
- Interpolação de strings

## 🚧 Limitações do projeto
- Não há validação de entrada (inputs inválidos podem gerar exceções)
- Não há separação em métodos ou classes (tudo está no `Main`)
- Não há tratamento de erros (try/catch)

## 🚀 Possíveis melhorias
- Implementar validação de entrada
- Separar lógica em métodos (ex: `CalcularIMC()`)
- Adicionar tratamento de exceções
- Classificação do IMC (baixo peso, normal, sobrepeso etc.)
